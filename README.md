# Siroon

Outil d’organisation pour restaurant / salle : journée, planning, menu et événements.

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Parcours

- **Aujourd’hui** — date, événements du jour, accès rapide
- **Planning** — vue des 3 salles et du calendrier
- **Menu** — aliments par catégorie, prix au kg ou à l’unité
- **Nouvel événement** — salle, menu, extras, total

Données stockées en local sur l’appareil (`localStorage`).
